🧭 What Is LLaya?

LLaya is a helper for software that needs to make decisions from text. It runs the Laya typed-decision model directly on your computer. The model stays local, which means it does not depend on a remote server.

The application can answer as JSON text or as Lua tables. JSON is a common text format used by many apps. Lua tables are organized lists that Lua programs can read easily. This makes LLaya useful for local AI, text classification, and decision-making tasks.

LLaya is open source and is designed as an alternative to Jev. It supports Lua 5.1, Lua 5.2, Lua 5.3, and Lua 5.4.

LLaya is built for everyday use on a normal computer. You do not need to be a programmer to download it, and you do not need to set up a web server or install Python. The model runs in the same process as your Lua program, which keeps everything fast and private.

💡 What You Can Do With It

LLaya is built for decisions. You give it text, and it gives you an answer in a structured form. This is useful when you want to sort messages, label text, or route a request to the right place.

Text classification is one common example. A program can send a piece of text to LLaya and receive a category back. Because the answer arrives as JSON text or as a Lua table, it is simple for another program to read the result and act on it.

Decision-making is another example. Instead of a long back-and-forth conversation, LLaya focuses on choosing an option. That makes it a good fit for automated helpers, small tools, and scripts that need a quick local answer.

Local AI also means your text stays on your computer. For people who care about privacy, that is a meaningful advantage over tools that send data to an outside service.

❓ Common Questions

Do I need to know how to program?

No. You can download and run LLaya without any programming knowledge. It is a local application that you start on your own computer.

Do I need to install Python?

No. LLaya is a binding for LibLayaX and does not use Python at all.

Do I need a server?

No. There is no server to run. The model works inside the same process as the program that uses it.

Does it work offline?

Yes. Once LLaya is on your computer, it runs locally and does not need an internet connection.

Is it free?

LLaya is open source. Visit the download link to learn more about the project and its license.

What does "answers as JSON text or Lua tables" mean?

It means the result of a decision can be returned in two convenient formats: as plain text that follows the JSON pattern, or as a structured Lua table that a Lua program can read directly.
